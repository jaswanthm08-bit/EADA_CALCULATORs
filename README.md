# Orbit Calculator

A lightweight, responsive calculator built with plain HTML, CSS, and JavaScript. It runs directly in a browser with no build step or dependencies.

## Run it

Open `index.html` in any modern browser.

## Features

- Addition, subtraction, multiplication, and division
- Percent, sign toggle, decimal input, clear, and backspace
- Keyboard support for digits, `+`, `-`, `*`, `/`, `.`, `%`, Enter, Backspace, and Escape
- Responsive layout and visible keyboard focus states
- Handles division by zero with a clear error state
